회차(시험 시각)는 미리 들어가 있어요 — 11/20(금) 4시 · 6시 · 7시, 11/21(토) 12시 · 2시. 새 시각이 필요하면 ＋ 회차 추가.

명단에 없는 학생 (신규)

1
＋ 학생 추가

이름 · 학교 · 학생 번호 · 학부모 번호 · 회차를 넣어요.

2
번호는 꼭 하나 이상

학생 번호가 있으면 학생 번호로, 없으면 학부모 번호로 입력 링크가 가요. 번호 뒷 4자리는 학생이 직접 들어올 때 본인 확인 번호가 돼요.

3시험 당일 흐름

시작예: 16:00
A형·B형 시험지 나눠 주기
시험 50분16:00~16:50
16:50 자동학생 입력 열림 + 그 회차 학생에게 알림
입력 2시간18:50 까지 폰으로 답 입력
  • A형 = 중3-1 범위, B형 = 공통수학1(다항식~여러 가지 부등식). 시험지 맨 위에 형이 적혀 있어요. 두 장 다 보는 학생은 하나씩 입력해요.
  • 시험이 끝나면 시험지는 학생이 갖고 폰으로 답을 옮겨요(교실에서 바로 해도 되고, 집에 가서 해도 돼요 — 마감 전까지).
  • 일찍 끝난 회차는 그 회차 카드의 지금 열기를 두 번 누르면 바로 열리고 알림이 가요.

시험 끝나고 학생에게 해 줄 말

그대로 읽어 주세요 지금 카톡(또는 문자)으로 '레벨테스트 답 입력' 링크가 가요. 누르면 바로 시작돼요.
시험지 맨 위에 적힌 A형/B형을 고르고, 시험지에 쓴 답을 그대로 옮겨요.
문항마다 확실 · 애매 · 찍음 · 안 풂 중에 솔직하게 하나 골라요 — 반 배정·상담에 써요.
맨 아래 질문까지 답하고 제출을 두 번 누르면 끝. 틀린 문항이 뜨면 실수였는지 몰랐는지만 골라 주세요.
링크가 안 오면 ukan.kr/dashboard/lt 에 들어가서 이름이랑 휴대폰 뒷 4자리를 넣으면 돼요.

4언제 어떤 알림이 가나요

알림은 학생 입력 링크 하나뿐이에요. 예약 확인·시험 안내·결과 안내 알림은 자동으로 가지 않아요(필요하면 데스크가 직접 연락).

언제누구에게무엇
회차 시험이 끝나는 시각
시작 + 50분 (예: 16:00 회차 → 16:50)		그 회차에 배정된 학생 전원알림톡 「레벨테스트 답 입력」 — 개인 입력 링크 + 입력 마감 시각
이미 열린 회차에 나중에 배정·추가했을 때그 학생만같은 알림이 바로 가요
지금 열기를 눌렀을 때그 회차 학생 전원같은 알림이 바로 가요
알림 다시를 눌렀을 때그 학생만같은 알림 다시 (1~2분 걸려요)
학부모에게 문자 보내기 · 한꺼번에 문자 보내기를 눌렀을 때학부모 번호(반배정이 있는 학생만)문자 「레벨테스트 결과와 반 배치 안내」 — 결과 분석지 링크 + 곧 데스크에서 상담 전화 드린다는 안내 (1~2분)

받는 번호

  • 학생 번호로 가요. 학생 번호가 없으면 학부모 번호(여러 개면 첫 번호)로 가요.
  • 카카오 알림톡이 안 되는 폰이면 같은 내용이 문자로 가요.

알림이 안 가는 경우

  • 회차 미정인 학생 — 꼭 회차에 배정해 주세요.
  • 번호가 없는 학생 — 알림 칸에 번호 없음. 수정에서 번호를 넣고 알림 다시, 또는 링크로 복사해 직접 보내 주세요.
  • 입력 시간(2시간)이 다 지난 회차에 배정한 학생 — 링크로 직접 보내 주세요.

표시뜻
알림톡 감 문자 감보냈어요
번호 없음번호가 없어서 못 보냈어요 → 번호 넣고 알림 다시
실패번호가 틀렸거나 발송 오류 → 번호 확인 후 알림 다시, 안 되면 링크로 직접
—아직 보낼 때가 아니에요(회차 시험이 끝나기 전)

6결과 보기

  • 학생 결과 탭: 학생이 제출하면 바로 채점돼서 올라와요. 머리글을 누르면 정렬(누른 순서대로 우선순위).
  • 학생 줄을 누르면 상담 카드 — 문항별 색 띠 · 레벨별/단원별 막대 · 틀린 문항에서 고른 선지로 본 오개념 · 학생이 고른 틀린 이유 · 선행 정도 설문. 인쇄로 상담 때 쓰세요.
  • 읽는 법: 확실 정답 = 확실하다고 하고 맞힌 문항(실력) · 찍음 뺀 점수 = 찍어서 맞힌 점수를 뺀 점수 · 실수 없으면 = 학생이 실수라고 한 문항만 맞았다면.

7반배정 · 학부모 리포트 · 상담 전화

1
반배정 — 학생 결과 표의 '반배정' 칸에서 골라요

심화 · 기본(월수금) · 기본(화목토) · 기본(요일미정) · 미정. 고르면 바로 저장되고 누가 정했는지 남아요. 상담 카드 맨 위에서도 고를 수 있어요.

2
학부모 리포트 보내기 — 반배정이 있어야 보낼 수 있어요

한 명씩: 상담 카드 → 학부모 리포트 → (선생님 한마디를 쓰고) 학부모에게 문자 보내기 두 번 누르기.
한꺼번에: 학생 결과 표 위 한꺼번에 문자 보내기 — 반배정이 있고 아직 안 보낸 학생 전부.

3
상담 전화 — 상담 카드의 '통화할 때 이 순서로' 보고 전화해요

학부모 번호를 누르면 바로 걸려요. 통화가 끝나면 결과(통화 완료 · 부재중 · 다시 연락 · 고민 중 · 등록 확정 · 등록 안 함)를 고르고 메모 → 상담 기록 저장. 표의 '상담' 칸에 보여요.

리포트에 들어가는 것 — 반 배치(요일·12/1 개강) · 선생님 한마디 · 총점과 응시자 평균 · 수준별/단원별 성취 · 문항별 색 띠 · 풀이 습관(확실·찍음·실수·틀림·못 풂) · 분석 요약 · 틀린 문항과 자주 하는 착각 · 선행 이력. 정답과 선지는 안 들어가요(같은 시험을 볼 학생이 남아 있어서).
문자가 안 갔어요 — 표의 '리포트' 칸이 번호 없음이면 학부모 번호가 없는 거예요. 명단에서 번호를 넣고 다시 보내거나, 상담 카드 링크 복사로 카톡에 붙여 보내 주세요. 실패면 칸에 마우스를 올려 이유를 보고 유강쌤께 말해 주세요.

8이럴 땐

학생이 링크를 못 받았대요회차·예약 탭에서 그 학생 알림 칸 확인 → 알림 다시 또는 링크(복사해서 카톡으로). 급하면 학생이 ukan.kr/dashboard/lt 에 들어가 이름 + 휴대폰 뒷 4자리(본인 또는 부모님 번호)로 들어가도 돼요.
"명단에서 이름을 못 찾았어요"가 떠요학생 화면의 처음 왔거나 명단에 없어요로 학생이 직접 등록할 수 있어요. 그러면 명단에 확인 표시가 붙어요 — 수정에서 정보 확인 후 저장하면 표시가 없어져요.
학생이 답을 잘못 옮겨서 냈어요학생 결과 → 그 학생 상담 카드 → 제출 지우고 다시 받기(두 번 누르기). 학생이 같은 링크로 다시 입력하면 돼요. 지운 기록은 따로 보관돼요.
학생 정보(이름·번호·학교)가 틀려요명단 또는 회차 탭의 학생 줄 수정. 번호를 바꾸면 본인 확인 번호(뒷 4자리)도 같이 바뀌어요.
학생을 지우고 싶어요수정 → 학생 삭제(두 번 누르기). 이미 제출한 학생은 결과 보호를 위해 지울 수 없어요.
입력 마감이 지났는데 아직 안 낸 학생이 있어요유강쌤께 말해 주세요(입력 창을 다시 열 수 있어요).
화면이 안 바뀌어요오른쪽 위 새로고침. 입력이 열려 있는 동안은 30초마다 저절로 새로 고쳐져요.
