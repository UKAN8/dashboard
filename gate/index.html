④ 학부모 리포트 — 통과한 학생만 렌더, 경고 학생은 보류

  






  
실제 시스템에서는 이 검수기가 GitHub Actions 안에서 render_daily.py 2-b 단계로 돌고, 결과를 render/verify_<날짜>.txt와 manifest의 verified 필드에 남깁니다. 경고가 있으면 콘솔에서 해당 칸을 고치고 [마감]을 다시 누르면 서버가 재렌더합니다.

  
배운 것. 첫 실행에서 경고 48건이 전부 오탐이었습니다. "써킷", "R0", "OPT"를 내부 용어로 등록했더니 진도·과제 칸의 교재 이름까지 잡은 겁니다. 학부모가 아는 이름과 진짜 내부 용어의 경계는 현장 사람만 그을 수 있습니다.

  
이 페이지의 이름·점수·코멘트는 전부 가상입니다. 입력은 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다.
