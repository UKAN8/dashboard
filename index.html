반 선택

오늘 입력을 못 불러왔다 — 입력을 잠갔다

화면의 빈칸이 서버를 덮는 것을 막으려고 잠근 것이다. 이미 저장된 값은 그대로 있다. 새로고침해서 다시 들어와라(로그인이 풀렸으면 코드로 재로그인). 그래도 같으면 세션에 말해라.

저장이 서버에 들어가지 않는다

지금 화면의 입력은 저장 안 된 상태다 — 새로고침하면 사라진다. 입력을 멈추고 관리자에게 알려라. 이 줄은 저장이 다시 성공하면 스스로 사라진다.

수업 정보 저장됨 ✓

지난 날짜를 보고 있다 — 저장도 이 날짜로 들어간다
정답을 넣으면 학생 표가 답 입력 칸으로 바뀐다.
전원 채점 뒤 누른다. 학생 포털에 개념 진단이 뜨고, 제출한 학생부터 진단 반영 PT가 만들어진다

마감 후 흐름

자동 — 데일리 리포트: 마감이 서버를 깨워 렌더된다(보통 5분 안) → 학습현황 ↗ 데일리에서 확인
재마감 — 수정 후 [마감]을 다시 누르면 그날 데이터를 리셋하고 다시 적재·렌더한다 (0818)
직접 — 복습 루프: 아래 복습 루프 카드에서 [루프 만들기]→[보내기] · 추가학습 문제지: [추가학습] 탭
주의 — 리뷰테스트를 새로 만든 날은 세션에서 유형 매핑(render_now)이 먼저다. 매핑 없이 렌더되면 오답 태그가 빈다
진행 상황은 상단 ⚙ 작업에서 본다 — 새로고침해도 안 사라진다

오늘 물을 것

반을 고르면 그 학년 풀에서 문항을 불러온다. 진도에 가까운 3개가 미리 체크된다.

복습 루프

오늘 물을 것(문항)은 제작 세션이 쓴다. 여기서는 누구에게 무엇이 나갈지를 만들고 보낸다.
누가 냈고 누가 안 냈나 → 조회 [루프] 탭 · 발송 현황

주간고사 성적 성적 xlsx + 분석시트

성적 xlsx 를 고르면 회차·학년을 파일 이름에서 읽고, 무엇이 들어갈지 먼저 보여준다.

내신 성적표 학교 중간·기말

시행년 = 기준년 − (현재학년 − 시험학년). 등급·석차·과목평균·수강자수는 손으로 채운 값을 덮지 않는다.

오늘 부를 학생

지정해 두면 서버가 학생별로 연습장에 풀고 답만 넣는 세트를 만들어 주소까지 올린다. 짚은 유형이 파트1, 남는 자리는 루프함이 인증 밀린 것부터 채운다.

리뷰테스트 만들기

범위는 묻지 않는다 — 시험일 직전 수업의 이번과제를 서버가 읽는다. 문항은 다른 반이 이미 푼 원문항만 재사용한다(변형·창작 없음). 완성되면 hwpx 내려받기 링크가 여기 뜬다.
⚠ 서버는 PDF 시각검수를 못 한다 — 인쇄물에서 하단 넘침만 한 번 훑을 것. 후보가 부족하면 그 사유가 그대로 뜬다(그 회차는 제작 세션 영역).
