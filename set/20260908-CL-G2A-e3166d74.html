사잇값 정리

정리의 내용

함수 f(x) 가 닫힌구간 [a, b] 에서 연속이고 f(a)≠f(b) 이면,

f(a) 와 f(b) 사이의 임의의 값 k 에 대하여 f(c)=k 인 c 가 열린구간 (a, b) 에 적어도 하나 존재한다.

실근의 존재를 보이는 데 쓴다

k=0 인 경우가 방정식의 실근이다. f(x) 가 [a, b] 에서 연속이고 f(a)f(b)<0 이면

방정식 f(x)=0 은 열린구간 (a, b) 에서 적어도 하나의 실근을 갖는다.

f(a)f(b)<0

말할 수 있는 것과 없는 것

적어도 하나 존재한다는 것만 말한다. 근이 몇 개인지, 어디인지는 말하지 않는다.

또 f(a)f(b)>0 이라고 해서 그 구간에 실근이 없다고 단정할 수 없다.

푸는 순서

① 함수가 그 구간에서 연속인지 확인한다.

② 구간의 양 끝에서 함숫값의 부호를 구한다.

③ 부호가 바뀌는 구간을 찾아 실근의 존재를 말한다.

부호가 바뀌면 그 사이 어딘가에서 0 을 지난다. 연속이라는 가정이 빠지면 성립하지 않는다.
부호가 바뀌지 않아도 실근이 있을 수 있다. f(a)f(b)>0 을 실근이 없다는 근거로 쓰면 안 된다.

미분계수의 기하적 의미와 그래프에서 접선의 기울기 읽기

미분계수는 접선의 기울기

함수 y=f(x) 의 x=a 에서의 미분계수 f′(a) 는 그래프 위의 점 (a, f(a)) 에서의 접선의 기울기이다.

함숫값 f(a) 는 점의 높이이고, f′(a) 는 그 점에서 곡선이 기울어진 정도이다. 둘은 다른 양이다.

f′(a)=limh→0f(a+h)−f(a)h=(점 (a, f(a)) 에서의 접선의 기울기)

부호와 크기를 그림에서 읽기

접선이 오른쪽 위로 올라가면 f′(a)>0, 수평이면 f′(a)=0, 오른쪽 아래로 내려가면 f′(a)<0 이다.

기준이 되는 직선과 비교하면 크기도 읽을 수 있다. 직선 y=−x 의 기울기는 −1 이므로, 접선이 이 직선보다 가파르게 내려가면 f′(a)<−1 이고 완만하게 내려가면 −1<f′(a)<0 이다.

평균변화율은 두 점을 이은 직선의 기울기

x 의 값이 a 에서 b 까지 변할 때의 평균변화율 f(b)−f(a)b−a 는 두 점 (a, f(a)), (b, f(b)) 를 이은 직선의 기울기이다.

그림에서 이 직선과 한 점에서의 접선을 나란히 놓고 어느 쪽이 더 가파른지 비교하면 미분계수와 평균변화율의 대소를 판정할 수 있다.

f(b)−f(a)b−a=(두 점을 이은 직선의 기울기)

식을 세우지 않는다

그래프만 주어진 문제는 함수식을 구하지 않는다. 접선의 방향, 기준 직선과의 비교, 두 점을 이은 직선만으로 판정한다.

발문에 다항함수라고만 있으면 삼차함수로 단정하지 않는다. 차수를 정할 근거가 없다.

푸는 순서

① 물어보는 점에서 접선을 그려 방향을 읽는다. 올라가면 양, 수평이면 0, 내려가면 음.

② 기준 직선(y=x, y=−x 등)이나 두 점을 이은 직선과 가파른 정도를 비교한다.

③ 함수식 없이 부등호로 정리한다.

f′(a) 는 접선의 기울기, 평균변화율은 두 점을 이은 직선의 기울기. 둘 다 그림에서 직선의 기울어진 정도로 읽는다.
점이 높이 있다고 f′(a) 가 크다고 여기는 실수가 잦다. 함숫값의 크기와 접선의 기울기는 별개이다. 또 y=−x 보다 가파르게 내려가면 f′(a) 는 −1 보다 작다.

극한 조건으로 다항함수 결정

무한대 조건이 차수와 최고차항 계수를 준다

limx→∞f(x)xn 이 0 이 아닌 값 α 로 수렴하면 f(x) 는 n 차이고 최고차항의 계수가 α 다.

limx→∞f(x)xn=α (α≠0) ⇒ f(x)=αxn+⋯

유한한 점의 조건이 나머지 계수를 준다

limx→af(x)x−a 가 존재하면 f(a)=0 이다. 그러므로 f(x) 는 x−a 를 인수로 가진다.

limx→0f(x)x 가 존재하면 상수항이 없고, 그 극한값이 일차항의 계수다.

미지수를 최소한으로 놓는다

두 조건에서 얻은 것을 먼저 반영해 f(x) 를 세운다. 남은 계수만 미지수로 둔다.

처음부터 모든 계수를 미지수로 놓으면 식이 불어나 계산이 길어진다.

푸는 순서

① 무한대 조건으로 차수와 최고차항 계수를 정한다.

② 그 꼴로 f(x) 를 놓는다. 남은 계수만 문자로 둔다.

③ 유한한 점의 조건을 넣어 남은 계수를 정한다.

차수와 최고차항 계수는 무한대가, 나머지 계수는 유한한 점이 정해 준다.
limx→∞f(x)xn=0 이면 f 의 차수가 n 보다 낮다는 뜻이다. n 차라고 단정하면 안 된다.

평균변화율

정의

x 의 값이 a 에서 b 까지 변할 때 함수 f 의 평균변화율은 함숫값의 변화량을 x 의 변화량으로 나눈 값이다.

분자와 분모는 같은 순서로 쓴다. 분자에서 b 쪽을 앞에 두었으면 분모에서도 b 쪽을 앞에 둔다.

ΔyΔx=f(b)−f(a)b−a

그래프에서의 뜻

평균변화율은 두 점 (a, f(a)),(b, f(b)) 를 이은 직선의 기울기다.

구간을 한 점으로 좁히면 이 값이 접선의 기울기, 곧 미분계수가 된다.

증분으로 쓰기

b=a+Δx 로 두면 평균변화율은 f(a+Δx)−f(a)Δx 가 된다.

구간의 끝이 a 에서 a+2 까지처럼 문자로 주어지면 이 꼴로 정리하는 편이 빠르다.

푸는 순서

① 구간의 양 끝 x 값을 정한다.

② 두 함숫값을 구해 차 f(b)−f(a) 를 만든다.

③ x 의 차 b−a 로 나눈다.

평균변화율은 두 점을 이은 직선의 기울기다. 한 점에서의 기울기가 아니다.
분자와 분모를 뒤집어 b−af(b)−f(a) 로 쓰는 실수가 잦다. 나누는 쪽은 언제나 x 의 변화량이다.

가우스 기호를 포함한 함수의 연속

가우스 기호의 뜻

[x] 는 x 를 넘지 않는 최대의 정수이다. [2.7]=2, [3]=3, [−0.5]=−1 이다.

n≤x<n+1 (n 은 정수)이면 [x]=n 이다. 정수를 지날 때마다 값이 1 씩 뛴다.

n≤x<n+1 ⟹ [x]=n

정수에서의 좌극한과 우극한

정수 n 에서 x→n− 이면 [x]=n−1, x→n+ 이면 [x]=n 이다. 좌극한과 우극한이 다르므로 y=[x] 는 모든 정수에서 불연속이다.

[x−2] 처럼 안이 x−k 꼴이면 그래프를 x 축 방향으로 k 만큼 평행이동한 것이므로 뛰는 자리는 여전히 정수이다.

닫힌구간의 끝점

닫힌구간 [a, b] 에서 연속을 따질 때 끝점은 구간 안쪽의 극한만 본다. 왼쪽 끝 x=a 는 우극한과 f(a) 를, 오른쪽 끝 x=b 는 좌극한과 f(b) 를 비교한다.

f(x)=[x−2] 를 [1, 5] 에서 보면 x=1 은 우극한 −1=f(1) 이라 연속이고, x=5 는 좌극한 2≠f(5)=3 이라 불연속이다.

다른 식을 곱한 경우

g(x)[x] 는 정수 n 에서 좌극한 g(n)(n−1), 우극한 g(n)n 이다. 이 둘이 같으려면 g(n)=0 이어야 한다.

곱한 식이 그 정수에서 0 이 되면 뛰는 폭이 눌려 연속이 되고, 0 이 아니면 불연속이다.

푸는 순서

① 가우스 기호 안이 정수가 되는 x 를 구간 안에서 모두 찾는다.

② 각 자리에서 좌극한, 우극한, 함숫값을 비교한다. 끝점은 안쪽 극한만 본다.

③ 다른 식이 곱해져 있으면 그 식이 0 이 되는 정수는 연속으로 돌린다.

[x] 는 정수마다 뛴다. 닫힌구간의 끝점은 안쪽 극한 하나만 함숫값과 비교한다.
오른쪽 끝점을 무심코 연속으로 세거나, 왼쪽 끝점을 불연속으로 세는 실수가 잦다. 끝점마다 안쪽 극한과 함숫값을 실제로 비교한다.
