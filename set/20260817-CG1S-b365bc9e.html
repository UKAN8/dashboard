1접선의 방정식3 (원 밖의 점)단답

점 (3, 4)에서 원 x2+y2=5에 그은 두 접선의 기울기의 곱을 구하여라.

2내분점1 (분점)단답

두 점 A(−3, 8), B(7, −2)에 대하여 선분 AB를 3:2로 내분하는 점의 좌표를 (a, b)라 할 때 ab의 값을 구하여라.

3접선의 방정식2 (기울기)단답

원 x2+y2=9에 접하고 기울기가 2인 두 직선의 y절편의 곱을 구하여라.

4점과 직선 사이의 거리4 (삼각형의 넓이)단답

세 점 A(−2, 3), B(4, 1), C(2, k)를 꼭짓점으로 하는 삼각형 ABC의 넓이가 10이 되도록 하는 모든 실수 k의 값의 합을 구하여라.

5직선의 방정식의 해석7 (수직이등분선)단답

두 점 A(1, 2), B(5, 4)에 대하여 선분 AB의 수직이등분선이 x축, y축과 만나는 점을 각각 P, Q라 할 때 삼각형 OPQ의 넓이를 구하여라. (단, O는 원점이다.)

6직선에 대한 대칭이동단답

점 (2, 5)를 직선 y=2x−1에 대하여 대칭이동한 점의 좌표를 (a, b)라 할 때 a+b의 값을 구하여라.

7접선의 방정식1 (접점)단답

원 x2+y2=13 위의 점 (2, −3)에서 원에 그은 접선의 x절편을 구하여라.

8내분점6 (사각형 관련정리)단답

평행사변형 ABCD의 세 꼭짓점이 A(1, 2), B(5, 3), C(7, 8)일 때 꼭짓점 D의 좌표를 (a, b)라 하자. a+b의 값을 구하여라.

9두 점 사이의 거리의 활용1 (같은 거리에 있는 점)단답

두 점 A(1, 4), B(5, 2)로부터 같은 거리에 있는 y축 위의 점의 y좌표를 구하여라.

10원의 방정식 세우기2 (지름의 양 끝점)단답

두 점 A(−3, 2), B(5, 8)을 지름의 양 끝 점으로 하는 원의 방정식을 (x−a)2+(y−b)2=c 꼴로 나타낼 때 a+b+c의 값을 구하여라. (단, a, b, c는 상수이다.)

11활용1 (제곱의 합의 Mm)단답

두 점 A(1, 3), B(5, 7)과 x축 위의 점 P에 대하여 AP―2+BP―2의 최솟값을 구하여라.

12원의 방정식 세우기1 (중심과 반지름)단답

중심이 (2, −3)이고 점 (5, 1)을 지나는 원의 방정식을 x2+y2+Ax+By+C=0 꼴로 나타낼 때 A+B+C의 값을 구하여라. (단, A, B, C는 상수이다.)

13원과 직선의 위치 관계1 (교점의 개수)단답

직선 y=mx+4와 원 x2+y2=2가 만나지 않도록 하는 정수 m의 개수를 구하여라.

14기호와 의미3 (원소의 개수)단답

100 이하의 자연수 전체의 집합에서 3의 배수의 집합을 A, 4의 배수의 집합을 B라 할 때 n(A∪B)의 값을 구하여라.

15접선의 방정식4 (공통접선)단답

두 원 x2+y2=25, (x−3)2+(y−4)2=4의 공통접선이 두 원과 만나는 접점을 각각 P, Q라 할 때 선분 PQ의 길이를 구하여라.

16원과 직선의 위치 관계2 (원과 현)단답

원 (x−1)2+(y−2)2=25와 직선 3x+4y−31=0이 만나서 생기는 현의 길이를 구하여라.

17활용1 (자취의 방정식)단답

두 점 A(−2, 0), B(4, 0)에 대하여 PA―:PB―=1:2를 만족시키며 움직이는 점 P의 자취는 원이 된다. 이 원의 반지름의 길이를 구하여라.

18내분점4 (같은 비의 분점으로 이루어진 삼각형의 무게중심)단답

세 점 A(3, 7), B(−5, 2), C(8, −3)을 꼭짓점으로 하는 삼각형 ABC가 있다. 세 선분 AB, BC, CA를 각각 2:1로 내분하는 점을 차례로 P, Q, R라 하자. 삼각형 PQR의 무게중심의 좌표를 (a, b)라 할 때 a+b의 값을 구하여라.

19원의 방정식 세우기3 (지나는 세 점)단답

세 점 (2, 0), (−2, 0), (0, 4)를 지나는 원의 중심을 (a, b), 반지름의 길이를 r라 할 때 a+b+r의 값을 구하여라.

20점과 직선 사이의 거리2 (거리 조건)단답

점 (1, a)와 직선 3x+4y−5=0 사이의 거리가 2일 때 모든 실수 a의 값의 합을 구하여라.

21직선의 방정식의 해석3 (직선으로 둘러싸인 도형의 넓이)단답

세 직선 y=x, y=−2x+6, y=0으로 둘러싸인 도형의 넓이를 구하여라.

22활용5 (중선의 정리)단답

삼각형 ABC에서 AB―=7, AC―=5, BC―=8 이다. 변 BC의 중점을 M이라 할 때 AM―2의 값을 구하여라.

23원소배치해석 (원소의 개수 조건, 모든 원소의 합 또는 곱)단답

두 집합 A, B가 A∩B={3, 7}, A∪B={1, 3, 5, 7, 9}, A−B={1, 9}를 만족시킬 때 집합 B의 모든 원소의 합을 구하여라.

24두 점 사이의 거리1 (수직선)단답

수직선 위의 두 점 A(a3−7a), B(3) 사이의 거리가 3이 되도록 하는 서로 다른 실수 a의 개수를 구하여라.

25직선의 방정식의 해석8 (세 직선의 위치 관계)단답

세 직선 2x−y+1=0, x+y−4=0, ax−y+3=0이 삼각형을 이루지 않도록 하는 모든 실수 a의 값의 합을 구하여라.

26내분점5 (삼각형 관련정리)단답

세 점 A(1, 2), B(4, 6), C(13, −3)을 꼭짓점으로 하는 삼각형 ABC에서 각 A의 이등분선이 변 BC와 만나는 점을 D(a, b)라 할 때 a+b의 값을 구하여라.

27점과 직선 사이의 거리6 (Mm)단답

실수 k의 값에 관계없이 직선 kx−y+2k+5=0은 항상 일정한 점을 지난다. 점 A(1, 1)과 이 직선 사이의 거리의 최댓값을 구하여라.
