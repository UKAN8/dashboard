좌극한·우극한과 극한값의 존재

극한은 x=a 를 빼고 본다

x→a 는 x 가 a 에 한없이 가까워지되 a 와 같아지지는 않는다는 뜻이다.

그래서 f(a) 가 정의되지 않아도 극한은 있을 수 있고, f(a) 가 있어도 극한값과 다를 수 있다.

lim⁡x→af(x)=L

한쪽씩 본 것이 좌극한과 우극한

x 가 a 보다 작은 쪽에서 다가가면 좌극한, 큰 쪽에서 다가가면 우극한이다.

두 값은 서로 다를 수 있다. 다르면 극한은 존재하지 않는다.

lim⁡x→a−f(x),lim⁡x→a+f(x)

좌우가 갈리는 자리

절댓값 기호가 있는 함수는 절댓값 안이 0 이 되는 곳에서 식이 바뀐다.

구간을 나누어 정의한 함수는 구간의 경계에서 식이 바뀐다. 이 두 자리에서는 반드시 좌우를 따로 본다.

푸는 순서

① 좌우가 갈리는 자리를 찾는다. 절댓값 안이 0 인 곳, 구간의 경계다.

② 그 자리의 좌극한과 우극한을 식을 바꿔 각각 구한다.

③ 두 값이 같은지 비교해 존재 여부를 판정한다.

극한의 존재는 좌극한 = 우극한 하나로 판정한다. f(a) 는 판정에 끼지 않는다.
좌극한과 우극한이 다른데도 값이 하나 나온다고 답하는 실수가 잦다. 두 값이 다르면 극한은 존재하지 않는다고 써야 한다.

극한 조건으로 다항함수 결정

무한대 조건이 차수와 최고차항 계수를 준다

lim⁡x→∞f(x)xn 이 0 이 아닌 값 α 로 수렴하면 f(x) 는 n 차이고 최고차항의 계수가 α 다.

lim⁡x→∞f(x)xn=α (α≠0) ⇒ f(x)=αxn+⋯

유한한 점의 조건이 나머지 계수를 준다

lim⁡x→af(x)x−a 가 존재하면 f(a)=0 이다. 그러므로 f(x) 는 x−a 를 인수로 가진다.

lim⁡x→0f(x)x 가 존재하면 상수항이 없고, 그 극한값이 일차항의 계수다.

미지수를 최소한으로 놓는다

두 조건에서 얻은 것을 먼저 반영해 f(x) 를 세운다. 남은 계수만 미지수로 둔다.

처음부터 모든 계수를 미지수로 놓으면 식이 불어나 계산이 길어진다.

푸는 순서

① 무한대 조건으로 차수와 최고차항 계수를 정한다.

② 그 꼴로 f(x) 를 놓는다. 남은 계수만 문자로 둔다.

③ 유한한 점의 조건을 넣어 남은 계수를 정한다.

차수와 최고차항 계수는 무한대가, 나머지 계수는 유한한 점이 정해 준다.
lim⁡x→∞f(x)xn=0 이면 f 의 차수가 n 보다 낮다는 뜻이다. n 차라고 단정하면 안 된다.

분수 꼴 함수가 연속일 조건

분모가 0이 되는 점만 문제가 된다

유리함수는 분모가 0 이 아닌 모든 점에서 연속이다.

따라서 분모가 0 이 되는 x=a 에서만 따로 따진다.

분자도 0이 되어야 한다

x=a 에서 극한값이 존재하려면 분자도 x=a 에서 0 이어야 한다.

분모가 0 인데 분자가 0 이 아니면 극한값이 존재하지 않는다.

f(a)=lim⁡x→ag(x)h(x)

약분한 뒤 함숫값과 맞춘다

분자와 분모에서 공통인수 (x−a) 를 약분한 뒤 x=a 를 대입한다.

그 값이 f(a) 와 같아야 비로소 연속이 된다.

푸는 순서

① 분모가 0 이 되는 x=a 를 찾는다.

② 분자에 x=a 를 대입한 값을 0 으로 놓는다.

③ 약분하여 극한값을 구하고 f(a) 와 같게 놓는다.

분자가 0 이 된다는 것은 필요조건일 뿐이다. 약분한 뒤의 극한값과 함숫값이 같은지까지 확인한다.
분자를 0 으로 만드는 식 하나만 세우면 미지수가 남는다. 극한값과 함숫값을 같게 놓는 식을 반드시 하나 더 세운다.
