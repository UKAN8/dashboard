미정계수의 결정; 00 꼴

00 꼴은 약분하라는 신호

x→a 에서 분자와 분모가 모두 0 으로 가면 둘 다 x−a 를 인수로 가진다.

인수분해하거나 유리화해서 x−a 를 약분한 뒤 x=a 를 넣는다.

미정계수를 정하는 두 규칙

분모가 0 으로 가고 극한값이 존재하면 분자도 0 으로 가야 한다.

분자가 0 으로 가고 극한값이 0 이 아니면 분모도 0 으로 가야 한다.

lim⁡x→af(x)g(x)=α,  lim⁡x→ag(x)=0 ⇒ lim⁡x→af(x)=0

규칙을 쓰는 순서가 정해져 있다

이 규칙은 미지수 하나를 먼저 없애는 도구다. 그것으로 식을 정리한 뒤에야 약분이 된다.

약분한 식에 x=a 를 넣어 얻은 값이 두 번째 조건이 된다.

푸는 순서

① 분모가 0 으로 가는지, 분자가 0 으로 가는지 확인한다.

② 두 규칙 중 맞는 것으로 미지수 하나를 먼저 정한다.

③ 인수분해나 유리화로 약분한 뒤 x=a 를 넣어 나머지를 정한다.

0 이 아닌 수를 0 으로 나눈 값은 유한할 수 없다. 두 규칙은 모두 이 한 문장에서 나온다.
두 번째 규칙에서 극한값이 0 이 아니라는 조건을 빠뜨리면 안 된다. 극한값이 0 이면 분모는 0 으로 가지 않아도 된다.

미분법의 공식과 곱의 미분법

기본 공식

(xn)′=nxn−1 (n 은 자연수), 상수의 도함수는 0, {cf(x)}′=cf′(x), {f(x)±g(x)}′=f′(x)±g′(x).

항마다 따로 미분해 더한다.

곱의 미분법

앞을 미분하고 뒤는 그대로, 더하기, 앞은 그대로 뒤를 미분한다.

각각 미분해서 곱하는 것이 아니다.

{f(x)g(x)}′=f′(x)g(x)+f(x)g′(x)

{g(x)}n 꼴

곱의 미분법을 거듭 쓰면 [{g(x)}n]′=n{g(x)}n−1g′(x) 이다. 안쪽 도함수 g′(x) 를 빠뜨리지 않는다.

y=(2x+1)3 이면 y′=3(2x+1)2⋅2=6(2x+1)2.

값만 필요할 때

f′(1) 처럼 한 점의 값만 물으면 전개하지 말고 곱의 미분법 식에 바로 대입한다.

어느 인수가 그 점에서 0 이면 그 항은 통째로 사라진다.

푸는 순서

① 두 인수 f,g 를 정하고 각각 미분한다.

② f′g+fg′ 로 세운다.

③ 값을 물으면 그 점을 바로 대입한다.

곱의 미분법은 미분·그대로 + 그대로·미분. 한 점의 값은 전개 없이 대입.
{f(x)g(x)}′=f′(x)g′(x) 는 틀린 식이다. {g(x)}n 에서 g′(x) 를 빼먹는 실수도 잦다.

미분가능성과 연속성

화살표는 한 방향이다

x=a 에서 미분가능하면 그 점에서 연속이다. 거꾸로는 성립하지 않는다.

f(x)=∣x∣ 는 x=0 에서 연속이지만 좌미분계수가 −1, 우미분계수가 1 이라 미분가능하지 않다.

미분가능⇒연속,연속⇏미분가능

경계에서 세우는 두 식

구간에 따라 다르게 정의된 함수가 경계 x=a 에서 미분가능할 조건은 두 개다.

하나는 연속 조건, 하나는 좌미분계수와 우미분계수가 같다는 조건이다. 미지수가 둘이면 이 두 식을 연립한다.

lim⁡x→a−f(x)=lim⁡x→a+f(x)=f(a),f′(a−)=f′(a+)

절댓값이 곱해진 꼴

f(x)=∣x−a∣ g(x) 가 x=a 에서 미분가능할 조건은 g(a)=0 이다.

x>a 쪽은 (x−a)g(x), x<a 쪽은 −(x−a)g(x) 로 나누어 각각 미분해 견주면 나온다.

푸는 순서

① 경계에서 연속 조건을 세운다 — 좌극한, 우극한, 함숫값을 같게 놓는다.

② 양쪽을 각각 미분해 좌미분계수와 우미분계수를 같게 놓는다.

③ 두 식을 연립해 상수를 정한다.

미분가능은 연속을 포함한다. 그래서 조건이 하나가 아니라 둘이다.
기울기만 맞추면 끊어진 채 평행하게 어긋난 함수도 통과한다. 연속 조건을 반드시 함께 세운다.

구간별로 정의된 함수가 연속일 조건

확인할 곳은 이음매뿐이다

구간마다 다항함수로 주어졌다면 각 구간의 안쪽에서는 이미 연속이다.

따라서 식이 바뀌는 경계에서만 연속인지 따지면 된다.

경계에서 세 값을 맞춘다

경계 x=a 에서 좌극한, 우극한, 함숫값 셋을 같게 놓는다.

좌극한은 x<a 쪽 식에, 우극한은 x>a 쪽 식에 a 를 대입해 얻는다.

lim⁡x→a−f(x)=lim⁡x→a+f(x)=f(a)

경계가 둘이면 식도 둘이다

경계마다 식이 하나씩 나온다. 미지수가 두 개이면 경계도 두 곳이거나 다른 조건이 하나 더 있어야 한다.

푸는 순서

① 식이 바뀌는 경계를 모두 찾는다.

② 경계마다 좌극한, 우극한, 함숫값을 구한다.

③ 세 값을 같게 놓아 식을 세우고 미지수를 구한다.

다항식으로 정의된 구간의 내부는 저절로 연속이다. 이음매에서만 식을 세운다.
등호가 어느 쪽 식에 붙어 있는지 확인한다. x≥a 쪽에 등호가 있으면 f(a) 는 그 식으로 계산한다.

극한 조건으로 다항함수 결정

무한대 조건이 차수와 최고차항 계수를 준다

lim⁡x→∞f(x)xn 이 0 이 아닌 값 α 로 수렴하면 f(x) 는 n 차이고 최고차항의 계수가 α 다.

lim⁡x→∞f(x)xn=α (α≠0) ⇒ f(x)=αxn+⋯

유한한 점의 조건이 나머지 계수를 준다

lim⁡x→af(x)x−a 가 존재하면 f(a)=0 이다. 그러므로 f(x) 는 x−a 를 인수로 가진다.

lim⁡x→0f(x)x 가 존재하면 상수항이 없고, 그 극한값이 일차항의 계수다.

미지수를 최소한으로 놓는다

두 조건에서 얻은 것을 먼저 반영해 f(x) 를 세운다. 남은 계수만 미지수로 둔다.

처음부터 모든 계수를 미지수로 놓으면 식이 불어나 계산이 길어진다.

푸는 순서

① 무한대 조건으로 차수와 최고차항 계수를 정한다.

② 그 꼴로 f(x) 를 놓는다. 남은 계수만 문자로 둔다.

③ 유한한 점의 조건을 넣어 남은 계수를 정한다.

차수와 최고차항 계수는 무한대가, 나머지 계수는 유한한 점이 정해 준다.
lim⁡x→∞f(x)xn=0 이면 f 의 차수가 n 보다 낮다는 뜻이다. n 차라고 단정하면 안 된다.
