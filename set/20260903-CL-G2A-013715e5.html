함수의 극한의 대소 관계

부등식은 극한에서도 살아남는다

a 의 주변에서 f(x)≤g(x) 이고 두 극한이 모두 존재하면 limx→af(x)≤limx→ag(x) 이다.

부등호는 유지되지만 등호가 붙을 수 있다. 강한 부등호는 극한에서 약해진다.

조임 정리

세 함수가 f(x)≤h(x)≤g(x) 를 만족시키고 양 끝의 극한이 같으면 가운데도 그 값으로 간다.

가운데 함수의 식을 모르더라도 값이 정해진다는 것이 이 정리의 힘이다.

f(x)≤h(x)≤g(x), limx→af(x)=limx→ag(x)=α ⇒ limx→ah(x)=α

x→0 이면 먼저 x 로 나눈다

−x2−2x<f(x)<x2−2x 처럼 양 끝이 모두 0 으로 가는 부등식은 f(x)→0 만 알려 준다. 구하는 식에 f(x) 가 분모에 있으면 이것만으로는 00 이다.

세 변을 x 로 나누면 −x−2<f(x)x<x−2 가 되어 f(x)x→−2 가 나온다. 이 값이 진짜 재료다.

x<0 이면 나눌 때 부등호가 뒤집히지만 양 끝의 극한은 여전히 −2 로 같다. 방향이 바뀌어도 조임은 그대로 된다.

구하는 식을 재료의 꼴로 고친다

limx→0x{f(x)+4x}{f(x)}3+2{f(x)}2 은 분모와 분자를 x2 으로 나누면 분자는 f(x)x+4, 분모는 (f(x)x)2{f(x)+2} 가 된다.

이제 f(x)x→−2, f(x)→0 을 넣으면 −2+4(−2)2·2=14 이다.

푸는 순서

① 부등식의 세 변을 x 로 나누어 f(x)x 의 극한을 구한다(양 끝의 극한이 같은지 확인).

② 필요하면 f(x) 자체의 극한도 적어 둔다(보통 0).

③ 구하는 식의 분모와 분자를 같은 x 의 거듭제곱으로 나누어 f(x)x 꼴을 만든 뒤 대입한다.

부등식은 x 로 나눠서 f(x)x 의 극한을 먼저 만든다. 구하는 식도 같은 꼴이 나오도록 분모·분자를 나눈 뒤 대입한다.
f(x)→0 만 보고 00 이라 멈추면 안 된다. f(x) 가 분모에 있으면 f(x)x 의 극한이 필요하다는 신호다.

미분계수로 미정계수 결정

조건을 어느 함수에 넣는가

f(a)=k 는 f 에 넣는다. x=a 에서의 접선의 기울기가 k 라는 말은 f′(a)=k 이므로 f′ 에 넣는다.

둘을 섞어 넣으면 전혀 다른 식이 나온다. 먼저 f′(x) 를 구해 놓고 시작한다.

미지수 개수만큼 식을 만든다

미지수가 두 개면 서로 독립인 식이 두 개 필요하다. 함숫값 조건과 미분계수 조건은 서로 독립이다.

식을 세운 뒤에는 연립하여 계수를 정한다.

극한 조건도 두 식을 준다

limx→af(x)−kx−a=m 이 성립하면 분모가 0 으로 가므로 분자도 0 으로 가야 한다.

따라서 f(a)=k 이고, 그때 이 극한은 정의 꼴이 되어 f′(a)=m 이다. 한 줄에서 식 두 개가 나온다.

푸는 순서

① f′(x) 를 먼저 구한다.

② 함숫값 조건은 f 에, 기울기 조건은 f′ 에 대입해 식을 세운다.

③ 세운 식을 연립해 계수를 정한다.

함숫값 조건은 f 로, 기울기 조건은 f′ 로. 넣을 자리를 먼저 가른다.
f′(a)=0 을 f(a)=0 으로 읽는 실수가 잦다. 앞은 접선이 수평이라는 뜻이고 뒤는 함숫값이 0 이라는 뜻이다.

개념
분수 꼴 함수가 연속일 조건

분모가 0이 되는 점만 문제가 된다

유리함수는 분모가 0 이 아닌 모든 점에서 연속이다.

따라서 분모가 0 이 되는 x=a 에서만 따로 따진다.

분자도 0이 되어야 한다

x=a 에서 극한값이 존재하려면 분자도 x=a 에서 0 이어야 한다.

분모가 0 인데 분자가 0 이 아니면 극한값이 존재하지 않는다.

f(a)=limx→ag(x)h(x)

약분한 뒤 함숫값과 맞춘다

분자와 분모에서 공통인수 (x−a) 를 약분한 뒤 x=a 를 대입한다.

그 값이 f(a) 와 같아야 비로소 연속이 된다.

푸는 순서

① 분모가 0 이 되는 x=a 를 찾는다.

② 분자에 x=a 를 대입한 값을 0 으로 놓는다.

③ 약분하여 극한값을 구하고 f(a) 와 같게 놓는다.

분자가 0 이 된다는 것은 필요조건일 뿐이다. 약분한 뒤의 극한값과 함숫값이 같은지까지 확인한다.
분자를 0 으로 만드는 식 하나만 세우면 미지수가 남는다. 극한값과 함숫값을 같게 놓는 식을 반드시 하나 더 세운다.

구간별로 정의된 함수가 연속일 조건

확인할 곳은 이음매뿐이다

구간마다 다항함수로 주어졌다면 각 구간의 안쪽에서는 이미 연속이다.

따라서 식이 바뀌는 경계에서만 연속인지 따지면 된다.

경계에서 세 값을 맞춘다

경계 x=a 에서 좌극한, 우극한, 함숫값 셋을 같게 놓는다.

좌극한은 x<a 쪽 식에, 우극한은 x>a 쪽 식에 a 를 대입해 얻는다.

limx→a−f(x)=limx→a+f(x)=f(a)

경계가 둘이면 식도 둘이다

경계마다 식이 하나씩 나온다. 미지수가 두 개이면 경계도 두 곳이거나 다른 조건이 하나 더 있어야 한다.

푸는 순서

① 식이 바뀌는 경계를 모두 찾는다.

② 경계마다 좌극한, 우극한, 함숫값을 구한다.

③ 세 값을 같게 놓아 식을 세우고 미지수를 구한다.

다항식으로 정의된 구간의 내부는 저절로 연속이다. 이음매에서만 식을 세운다.
등호가 어느 쪽 식에 붙어 있는지 확인한다. x≥a 쪽에 등호가 있으면 f(a) 는 그 식으로 계산한다.

개념
미분가능성과 연속성

화살표는 한 방향이다

x=a 에서 미분가능하면 그 점에서 연속이다. 거꾸로는 성립하지 않는다.

f(x)=|x| 는 x=0 에서 연속이지만 좌미분계수가 −1, 우미분계수가 1 이라 미분가능하지 않다.

미분가능⇒연속,연속⇏미분가능

경계에서 세우는 두 식

구간에 따라 다르게 정의된 함수가 경계 x=a 에서 미분가능할 조건은 두 개다.

하나는 연속 조건, 하나는 좌미분계수와 우미분계수가 같다는 조건이다. 미지수가 둘이면 이 두 식을 연립한다.

limx→a−f(x)=limx→a+f(x)=f(a),f′(a−)=f′(a+)

절댓값이 곱해진 꼴

f(x)=|x−a|g(x) 가 x=a 에서 미분가능할 조건은 g(a)=0 이다.

x>a 쪽은 (x−a)g(x), x<a 쪽은 −(x−a)g(x) 로 나누어 각각 미분해 견주면 나온다.

푸는 순서

① 경계에서 연속 조건을 세운다 — 좌극한, 우극한, 함숫값을 같게 놓는다.

② 양쪽을 각각 미분해 좌미분계수와 우미분계수를 같게 놓는다.

③ 두 식을 연립해 상수를 정한다.

미분가능은 연속을 포함한다. 그래서 조건이 하나가 아니라 둘이다.
기울기만 맞추면 끊어진 채 평행하게 어긋난 함수도 통과한다. 연속 조건을 반드시 함께 세운다.
