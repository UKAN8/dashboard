좌극한·우극한과 극한값의 존재

극한은 x=a 를 빼고 본다

x→a 는 x 가 a 에 한없이 가까워지되 a 와 같아지지는 않는다는 뜻이다.

그래서 f(a) 가 정의되지 않아도 극한은 있을 수 있고, f(a) 가 있어도 극한값과 다를 수 있다.

limx→af(x)=L

한쪽씩 본 것이 좌극한과 우극한

x 가 a 보다 작은 쪽에서 다가가면 좌극한, 큰 쪽에서 다가가면 우극한이다.

두 값은 서로 다를 수 있다. 다르면 극한은 존재하지 않는다.

limx→a−f(x),limx→a+f(x)

좌우가 갈리는 자리

절댓값 기호가 있는 함수는 절댓값 안이 0 이 되는 곳에서 식이 바뀐다.

구간을 나누어 정의한 함수는 구간의 경계에서 식이 바뀐다. 이 두 자리에서는 반드시 좌우를 따로 본다.

푸는 순서

① 좌우가 갈리는 자리를 찾는다. 절댓값 안이 0 인 곳, 구간의 경계다.

② 그 자리의 좌극한과 우극한을 식을 바꿔 각각 구한다.

③ 두 값이 같은지 비교해 존재 여부를 판정한다.

극한의 존재는 좌극한 = 우극한 하나로 판정한다. f(a) 는 판정에 끼지 않는다.
좌극한과 우극한이 다른데도 값이 하나 나온다고 답하는 실수가 잦다. 두 값이 다르면 극한은 존재하지 않는다고 써야 한다.

∞∞ 꼴의 극한

분모의 최고차항으로 나눈다

x→∞ 에서 분자와 분모가 모두 발산하면 ∞∞ 꼴이다. 이 꼴은 그대로 값을 읽을 수 없다.

분자와 분모를 분모의 최고차항으로 모두 나눈다. 그러면 0 으로 가는 항만 남아 값이 보인다.

limx→∞1xn=0(n>0)

차수를 비교하면 답은 셋 중 하나

분자의 차수가 분모보다 낮으면 극한값은 0 이다.

차수가 같으면 최고차항 계수의 비다.

분자의 차수가 분모보다 높으면 발산한다.

무리식은 루트 안을 한 차수 낮게 읽는다

4x2+3x 의 차수는 1 이다. x>0 일 때 x 로 나누면 루트 안은 x2 으로 나눈다.

4x2+3xx=4+3x(x>0)

푸는 순서

① 분자와 분모의 차수를 확인한다.

② 분모의 최고차항으로 분자와 분모를 모두 나눈다.

③ 1xn 자리에 0 을 넣어 값을 읽는다.

나누는 기준은 언제나 분모의 최고차항이다. 분자를 기준으로 잡으면 안 된다.
차수가 같을 때 답하는 것은 최고차항 계수의 비뿐이다. 나눈 뒤 0 으로 가는 항까지 함께 세면 틀린다.

연속함수의 성질

합과 곱은 조건 없이, 몫만 조건이 붙는다

두 함수 f,g 가 x=a 에서 연속이면 cf(x), f(x)+g(x), f(x)−g(x), f(x)g(x) 도 x=a 에서 연속이다.

몫 f(x)g(x) 는 g(a)≠0 일 때에만 x=a 에서 연속이다.

기본이 되는 함수들

다항함수는 모든 실수에서 연속이다.

유리함수는 분모를 0 으로 만드는 값을 제외한 모든 실수에서 연속이다.

최대·최소 정리

함수 f(x) 가 닫힌구간 [a, b] 에서 연속이면 f(x) 는 그 구간에서 반드시 최댓값과 최솟값을 갖는다.

구간이 열려 있거나 불연속점이 있으면 이 보장은 사라진다.

푸는 순서

① 각 함수가 어디에서 연속인지 적는다.

② 몫의 꼴이면 분모가 0 이 되는 값을 찾는다.

③ 그런 값이 없도록, 또는 그 점에서 따로 연속이 되도록 조건을 세운다.

연산 중에서 조건이 붙는 것은 몫뿐이다. 분모가 0 이 되는 점이 있는지 먼저 확인한다.
최대·최소 정리는 닫힌구간에서만 말할 수 있다. 열린구간이거나 불연속점이 있으면 최댓값이 없을 수 있다.
